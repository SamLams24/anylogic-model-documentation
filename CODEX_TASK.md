# CODEX_TASK.md

## Première mission

1. Lire intégralement `AGENTS.md` et les fichiers qu'il impose.
2. Lire `MODEL_EVOLUTION.md` et construire une liste de contrôle des fonctionnalités qui doivent rester couvertes.
3. Lire `sources/base_document_extrait.md` sans modifier les données.
4. Cartographier les dix-huit chapitres historiques vers la structure cible de `DOCUMENT_PLAN.md`.
5. Identifier les doublons réels, en particulier entre :
   - chronologie détaillée ;
   - analyse des décisions ;
   - résultats intégrés ;
   - discussion académique ;
   - traçabilité agent par agent.
6. Proposer dans `MIGRATION_PLAN.md` un tableau `ancien emplacement -> nouvel emplacement -> action : conserver / fusionner / déplacer en annexe / supprimer comme répétition`.
7. Ajouter dans `MIGRATION_PLAN.md` une seconde matrice `fonctionnalité consolidée -> chapitre cible -> statut de preuve -> source attendue`, fondée sur `MODEL_EVOLUTION.md`.
8. Ne pas commencer la réécriture massive avant d'avoir produit ce plan.
9. Une fois le plan établi, migrer par lots de deux chapitres maximum, compiler et exécuter les contrôles après chaque lot.
10. Ne jamais inventer de nouvelles valeurs ni de nouvelles références.
11. Les captures doivent utiliser `\FigureOrPlaceholder` avec des noms stables dans `figures/`.
12. À chaque fin de lot, résumer uniquement les modifications factuelles, les sources utilisées et les points qui nécessitent encore une preuve.
