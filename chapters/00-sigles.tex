  \item[AHP] Analytic Hierarchy Process.
  \item[AM] Asset Management.
  \item[CMD] Préfixe des commandes clientes dans le modèle.

  \item[RDF] Resource Description Framework.
  \item[REAPPRO] Préfixe des ordres internes de réapprovisionnement dans le modèle.
  \item[RL] Reliability.
  \item[RS] Responsiveness.
  \item[SCOR] Supply Chain Operations Reference.
  \item[VSM] Value Stream Mapping.
  \item[WIP] Work In Process.
\end{description}
