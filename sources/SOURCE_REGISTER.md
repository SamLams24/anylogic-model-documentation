## Règles d'usage

Le modèle ALP et le JSON prouvent l'implémentation ou la configuration des éléments qu'ils contiennent. Ils ne prouvent pas l'exécution d'un scénario.

La paire Excel et ABox du run de validation VSM porte le même `runId` et le même instant de clôture de 2 343 s. Elle permet de publier les six indicateurs VSM et le PI dans le cadre du modèle. Le PCE reste estimé à partir de taux VA configurés, et les profils Bottom/Perfect restent à calibrer avant toute interprétation absolue.

Le Run A, les résultats historiques de panne, les pics de demande, la campagne qualité et la comparaison des modes restent non promus tant que leurs artefacts primaires ne sont pas fournis. Le goulot et l'arbitrage AHP observés dans le run VSM sont recevables pour cette exécution seulement.
